# DevDesk

DevDesk is a free, browser-based starter toolkit for people learning and practicing web development.

## Features
- HTML/CSS/JavaScript playground with a sandboxed preview
- JSON formatter, minifier, and validator
- Small library of reusable starter snippets
- Responsive layout and keyboard-friendly native controls
- No account, server, build step, or package installation required

## Run locally
1. Download or clone this repository.
2. Open `index.html` in a modern browser.
3. Edit code in the playground and choose **Run preview**.

## Project status
This is an early-stage starter project. It does not yet have published usage statistics or an established user community. Please report issues and suggest improvements honestly as the project develops.

## Roadmap ideas
