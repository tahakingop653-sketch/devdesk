# Contributing to DevDesk

Thanks for helping improve DevDesk!

1. Describe bugs or feature ideas in an issue.
2. Keep changes focused and explain why they help users.
3. Prefer accessible controls, responsive layouts, and clear error messages.
4. Do not add analytics, tracking, or external services without clearly documenting them.
5. Test the playground, JSON tools, and snippet copy buttons in a modern browser.

This project is early-stage; respectful feedback and beginner-friendly explanations are especially welcome.
